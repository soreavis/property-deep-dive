# Exit — Sub-Saharan Africa

> Part of [Exit — universal contract](../exit.md). Cross-region patterns + liquidity heatmap live there.

## 🇿🇦 South Africa
- **DOM**: Cape Town (Atlantic Seaboard/CBD/Southern Suburbs) ~60-120 / Johannesburg (Sandton/Rosebank/Houghton) 90-180 / Durban 120-200 / Pretoria 100-150
- **Commission**: **5-7.5% + 15% VAT (PPRA-regulated)** seller-side typical; net 5.75-8.625%
- **Contract**: sole mandate 90 d standard (PPRA-regulated since 2022)
- **MLS**: no MLS; Property24 + Private Property dominate
- **Discount**: 5-10% off asking; 2024-2026 closer to flat in Cape Town
- **Sell-side**: **CGT 40% inclusion rate on gain at marginal income tax** (effective max ~18% for individuals at 45% bracket); R2M primary-residence exemption per individual; **Section 35A 7.5% withholding on non-resident sellers (sale > R2M)** — withheld by buyer's conveyancer, remitted to SARS; commission 5-7.5%+VAT
- **Liquidity**: 🟢 HIGH Cape Town Atlantic Seaboard / City Bowl / Southern Suburbs (semigration magnet 2020-2026); 🟠 MEDIUM Sandton/Rosebank prime; 🔴 LOW Durban/Pretoria suburbs; VERY LOW rural
- **Quirks**: **"Semigration" northward-to-Cape-Town flow 2020-2026** = Cape Town outperforming JHB (top-end Atlantic Seaboard ZAR pricing diverging); **load-shedding** (electricity outages) drives backup-power premiums + accelerates emigration sales; **expropriation-without-compensation legislation (signed 2025)** politically narrow but material to international buyer perception; sectional title vs freehold distinction; rand volatility material to foreign-seller exit math

## 🇳🇬 Nigeria
- **DOM**: Lagos (VI / Ikoyi / Lekki Phase 1 / Banana Island / Oniru) ~150-300 / Lagos Mainland (Yaba / Surulere / Ikeja GRA) 200-365 / Abuja FCT (Maitama / Asokoro / Wuse 2 / Jabi) 150-300 / Port Harcourt / Calabar / Kano 200-500+ / regional 250-700+ [verify with state Lands Bureau / Federal Capital Development Authority]
- **Commission**: **5-10% seller-pays typical** (informal market — broker law nascent + ESVARBON / NIVS regulation evolving) + 7.5% VAT on commission where applicable; agency fees among the highest globally for resi
- **Contract**: bilateral sale agreement → state Lands Bureau registration; **Land Use Act 1978 — all land vested in state Governor** — only Statutory Right of Occupancy (CofO — Certificate of Occupancy) 99-yr leasehold for foreign / non-citizen buyers; Governor's consent required for transfers
- **MLS**: NO MLS; **PropertyPro.ng + Nigeria Property Centre + Lamudi Nigeria + Private Property Nigeria** dominate; agency-network thin beyond major Lagos VI/Ikoyi/Lekki + Abuja Maitama brokers
- **Discount**: 15-25% off asking; **NGN devaluation 2023-24 catastrophic ~70% loss vs USD** post-Tinubu reforms creates wide pricing band — **USD-pricing dominant in Lagos VI/Ikoyi prime** for foreign-buyer segment; Naira-pricing parallel for domestic
- **Sell-side**: **CGT 10% flat on gain** (PPP applies if held primary residence); commission 5-10% + 7.5% VAT; deed registration ~3-7% (state-by-state); **Form A documentation for FX repatriation** via banking channels — without Form A documentation of original USD import, exit proceeds in NGN only (similar EG Form 4 friction)
- **Liquidity**: 🟠 MEDIUM-LOW Lagos VI / Ikoyi / Lekki Phase 1 / Banana Island / Oniru prime (UK/IN/CN/LB diaspora demand); 🔴 LOW Lagos Mainland; 🟠 MEDIUM-LOW Abuja Maitama / Asokoro / Wuse 2 prime; 🔴 LOW Port Harcourt / Calabar / Kano; VERY LOW rural; **security risk requires private security + gated communities** narrows expat buyer pool to specific compounds
- **Quirks**: **Land Use Act 1978 — all land vested in state Governor** — only Statutory Right of Occupancy (CofO 99-yr leasehold) for foreign / non-citizen buyers; Governor's consent required for transfers (delays + corruption-vulnerable); **NO golden-visa via real estate** — STR-1 Investor visa USD 100k business is the longer-term pathway; naturalization 15+yr + Nigerian language + dual NOT allowed for native-born; ~218M pop (Lagos 22M largest African city); **NGN devaluation cycle 2023-24 catastrophic** ~70% loss vs USD post-Tinubu reforms; **Form A documentation for FX repatriation** mandatory; 2024-25 cost-of-living protests + Tinubu reforms ongoing; **security risk requires private security + gated communities** standard Lagos VI/Ikoyi/Lekki + Abuja Maitama/Asokoro; **energy autonomy mandatory** (generators + solar) — power infrastructure unreliable; English official + Pidgin universal + Yoruba/Igbo/Hausa; MTN / Glo / Airtel / 9mobile 5G limited Lagos / Abuja; NHIA + mandatory private health insurance for expats; medivac to ZA/UK/UAE common; coworking Workstation / Capital Square / Workbench / Regus VI/Ikoyi; CofO-vs-Governor's-Consent-vs-State-Land-Allocation distinction critical for title due-diligence

## 🇲🇺 Mauritius
- **DOM**: Tamarin / Black River / Rivière Noire west-coast scheme villas (IRS / RES / PDS) ~120-300 / Grand Baie / Pereybere north-coast 90-180 / Belle Mare / Trou-d'Eau-Douce east-coast 120-240 / Flic en Flac west 120-240 / Curepipe / Floréal / Vacoas highland (Plaines Wilhems) 60-120 / Port Louis / Beau Bassin secondary 120-240 [verify with EDB scheme registrar / Registrar General LAVIMS]
- **Commission**: **3-5% seller-pays typical** (Real Estate Agents — Mauritius / IPDA professional regulation evolving) + 15% VAT on commission; some agents structure 2-3% buyer + 2-3% seller
- **Contract**: bilateral promesse synallagmatique de vente (Art. 1589 Code Civil — French civil-law tradition) → notaire authentic deed → registration at Registrar General's Department + LAVIMS update; foreigners EDB-scheme-only OR G+2 ≥ MUR 6M acquisition
- **MLS**: NO formal MLS; **MyProperty.mu / Lexpressproperty / Lecho.mu / Pam Golding Mauritius / Knight Frank Mauritius / 5àSec Maurice / Park Lane Properties** dominate; EDB maintains scheme-development registry
- **Discount**: 5-10% off asking typical; **Finance Act 2025 5%→10% transaction-tax hike for non-citizens** (effective date contested across sources) creates negotiating leverage at signing for buyers; scheme villas more sticky than open-market G+2 apartments
- **Sell-side**: **NO CGT, NO inheritance, NO wealth tax** (UNIQUE selling point); rental income on holding subject to 0/10/20% PIT (Finance Act 2025 brackets); commission 3-5% + 15% VAT; notaire ~1% + Registrar General fees ~0.5-1%; **Pas Géométriques 81m coastal reserve non-purchasable** (state land — only leasable); EDB scheme management-company exit-approval requirements typical
- **Liquidity**: 🟢 HIGH Tamarin / Black River / Grand Baie / Belle Mare scheme villas (FR/UK/CH/EU retiree + relocation demand); 🟠 MEDIUM Flic en Flac / Pereybere / Trou-d'Eau-Douce; 🟠 MEDIUM Curepipe / Floréal highland (domestic + retirees seeking cooler climate); 🔴 LOW Port Louis / Beau Bassin / rural; cyclone-season stock turnover thin Dec-Apr
- **Quirks**: **EDB-scheme-only foreign acquisition** (Non-Citizens Property Restriction Act 1975) — IRS / RES / PDS / SCS / IHS / Smart City schemes OR G+2 apartment ≥ MUR 6M — open-market freehold BANNED for non-citizens otherwise; **Finance Act 2025: registration duty + LTT for non-citizens 5%→10%** (effective date contested across sources); Retirement Permit threshold raised USD 1,500/mo → USD 2,000/mo (Finance Act 2025); LAVIMS digital cadastre (PIN per parcel, 2-hour SLA at RGD); MUR managed-float against undisclosed basket — depreciated ~30→46/USD 2020-2025; cyclone Class I-IV warning system (Météo Maurice); WMA sewerage covers only ~30% — septic + soak-away dominant; ~1.24M pop / 5-digit postcodes / English official + French + Mauritian Creole; hybrid French civil + English common law

## 🇨🇻 Cape Verde
- **DOM**: Sal (Santa Maria / Espargos) ~120-300 (highly seasonal — winter Nov-Apr peak) / Boa Vista (Sal Rei / Praia da Chave) 150-365+ / Praia (Plateau / Achada Santo António / Palmarejo) 120-240 / Mindelo (São Vicente) historic 150-300 / interior Santiago + Barlavento highlands 250-500+ [verify with Direção Nacional do Cadastro / Conservatória do Registo Predial]
- **Commission**: **3-6% seller-pays typical** (Lusophone civil-law tradition; immobilier regulation evolving) + 15% IVA on commission
- **Contract**: bilateral promessa de compra e venda → escritura pública (public deed) before notário → Conservatória do Registo Predial registration → IPI/ITI declaration via Casa do Cidadão one-stop shop; foreign-buyer regime BROADLY PERMISSIVE (no nationality bar for urban + tourism property)
- **MLS**: NO formal MLS; **CVNetwork.cv / Imobiliaria.cv / SmartProperties Cabo Verde / EngelVölkers Cabo Verde / Knight Frank Sal-Boa Vista** dominate Sal/Boa Vista tourism corridor; cadastre coverage strongest in Sal/Boa Vista/Praia, weakest in interior Santiago + Barlavento highlands
- **Discount**: 5-15% off asking typical; **Lei 55/X/2025 IUP→IPI/ITI reform eff. 1 Jan 2026** creates short-term price-discovery distortion 2026 H1; tourism-zone (Sal / Boa Vista) more liquid than interior; ZDTI (Zonas de Desenvolvimento Turístico Integral) developments stickier
- **Sell-side**: **CGT included in IRPS 5-30% (residency-dependent)** — primary residence reinvestment exemption applies; **2025 corporate-income-tax cut to 20%** (was 22%); commission 3-6% + 15% IVA; notário ~0.5-1% + Conservatória ~0.5-1%; tourism-zone first-sale developer typically VAT 15%/0% with CONFOTUR-equivalent incentives
- **Liquidity**: 🟢 HIGH Sal Santa Maria / Boa Vista Sal Rei tourism-zone (UK/IT/FR/PT/DE retiree + holiday-let demand); 🟠 MEDIUM Praia Plateau / Achada Santo António prime; 🟠 MEDIUM Mindelo historic; 🔴 LOW interior Santiago + Barlavento highlands; VERY LOW rural unregistered; **diaspora-heir trap** ("herança partilhada" undivided shares — common cadastre weakness)
- **Quirks**: **Lei 55/X/2025 of 6 June 2025 — IUP REPEALED, replaced by IPI (0.1% annual) + ITI (1% transfer)** effective 1 Jan 2026; **CVE pegged EUR 1:110.265 since 1999** (Acordo de Cooperação Cambial with Portugal — IMF Article IV/ECF 2025-26 reaffirmed peg credibility); **NO FX risk for EUR-priced**; 2017 RBI "Permanent Residence for Foreign Investors" (~EUR 80-120k); UNESCO Cidade Velha (Santiago) — IPC restoration permits required; ~525k pop / 4-digit postcodes / Portuguese official + Crioulo lingua franca; 22 concelhos + 31 freguesias; **diaspora-heir trap** — verify all heirs' consent in cadastre-weak interior; cyclonic-distant (Atlantic, but Hurricane Fred Aug 2015 + Lorenzo Sep 2019 marginal exposure)

## 🇸🇨 Seychelles
- **DOM**: Mahé (Eden Island / Anse Royale / Beau Vallon / Glacis / Anse Etoile) ~150-365+ / Praslin (Côte d'Or / Anse Volbert / Baie Sainte Anne) 180-365+ / La Digue (small market — UNESCO buffer constraints) 200-500+ / outer-island private concession N/A (long-term lease only — Aldabra / Desroches / Astove typically tourism-operator-controlled) [verify with Seychelles Registration Office Land Registration Act Cap 107]
- **Commission**: **5-7% seller-pays typical** (small-market thin; HNW villa sector ~3-5%) + 15% VAT on commission; Eden Island concession route lower-friction
- **Contract**: bilateral Sale Agreement → notary attestation + Sanction Permit application (where non-Seychellois buyer) → registration at Seychelles Registration Office (Old Register deeds-of-title OR New Register Torrens-style — Praslin/La Digue conversion launched June 2024); **SPA moratorium LIFTED 20 March 2025**
- **MLS**: NO formal MLS; **Seychelles Real Estate Network / Property Seychelles / Andersons Mahé / Eden Island Resales / Knight Frank Indian Ocean** dominate; small-market thin pool of brokers
- **Discount**: 8-15% off asking typical; **Sanction Duty raised 11→12% effective 2025-03-20** + **IPT doubled 0.25→0.5% (foreigner-only) effective 1 Jan 2024** create higher exit-friction for foreign sellers — pricing has adjusted upward (offset) 2024-26; Eden Island condominium concession route (~7-9% all-in vs ~18-19% standard sanction) materially cheaper exit
- **Sell-side**: **NO individual CGT** (UNIQUE — selling point reinforced); 5% Stamp Duty + 12% Sanction Duty (foreigner-only on resale to non-Seychellois) + 15% VAT first-sale developer; commission 5-7% + 15% VAT; legal ~1-2%; **Eden Island concession route ~7-9% all-in vs ~18-19% standard sanction** (10pp cheaper)
- **Liquidity**: 🟢 HIGH Mahé Eden Island concession (HNW UK/IT/FR/CH/UAE/RU/IN demand — luxury-second-home apex); 🟠 MEDIUM Mahé Anse Royale / Beau Vallon / Glacis residential; 🟠 MEDIUM Praslin Côte d'Or / Anse Volbert; 🔴 LOW La Digue (small market + UNESCO buffer); VERY LOW outer islands (lease-only); **4-6 mm/yr SLR (2-3× global)** — Mahé east coast + La Digue + Praslin beachfronts highest exposure
- **Quirks**: **SPA (Sanction Permit Act) moratorium LIFTED 20 March 2025** for non-Seychellois — residential acquisition permitted under SCR 10M (~USD 670k) dwelling floor + SCR 4,000/m² bare-land minimum; **IPT 0.25→0.5% (foreigner-only) eff. 1 Jan 2024**; SCR managed-float since Nov 2008 (de-pegged amid 2008 sovereign-debt crisis); USD + EUR informally accepted in tourism segment; **Property purchase does NOT confer residency** in Seychelles (UNIQUE distinction vs PT/GR Golden Visa); Standard Residence Permit SCR 150,000 main applicant (5-yr); GOP framework SCR 1,000 + SCR 700/mo; PUC tariffs eff. 15 Jan 2026; Felleng 2013 + Fantala 2016 + Hidaya 2024 cyclone calibration; ~100k pop / 90% on Mahé / English working-language / Seselwa Creole + French co-official; mixed civil-law (Code Napoléon Cap 33) + common-law conveyancing

## 🇰🇪 Kenya
- **DOM**: Nairobi (Karen / Lavington / Westlands / Runda / Muthaiga / Kitisuru / Kileleshwa) ~120-250 / Nairobi secondary (Kilimani / Hurlingham / Lang'ata / Loresho) 150-300 / Mombasa (Nyali / Bamburi / Diani south coast) seasonal 150-365 / Naivasha / Nakuru / Kisumu (SGR corridor) 150-300 / regional 200-500+ [verify with Land Registration Authority — LRA / Ministry of Lands]
- **Commission**: **2-5% seller-pays typical** (Estate Agents Registration Board — EARB regulated since 1984; informal in practice beyond Nairobi/Mombasa major brokers) + 16% VAT on commission; some seller-only at 3-5%
- **Contract**: bilateral sale agreement → Land Registration Authority (LRA) registration via state Land Registry; **agricultural land restricted to citizens per Constitution Art. 65**; foreigners limited to 99-yr leasehold cap on freehold-equivalents (Constitution Art. 65 Sub-Article 1(b))
- **MLS**: NO MLS; **Property24 Kenya + BuyRentKenya + Hauzisha + Lamudi Kenya** dominate; **NLIMS (National Land Information Management System)** ArcGIS-based portal launched 2023 — searchable parcel data emerging; M-PESA mobile-money universal in admin (unique to KE)
- **Discount**: 5-15% off asking; SGR corridor / Naivasha / Nakuru / Kisumu post-2023 SGR-completion variance; 2024-2025 macro-tightening + post-election cycle digestion
- **Sell-side**: **CGT 15% flat on gain** (post-2023 reform — increased from 5% — verify KRA); Stamp Duty 2-4% buyer-side + LRA registration ~1% + agent 2-5% + 16% VAT; **non-resident sellers face KRA withholding** (verify s.45 ITA — bank-channel documentation required for FX repatriation)
- **Liquidity**: 🟢 MEDIUM-HIGH Nairobi Karen / Lavington / Westlands / Runda / Muthaiga / Kitisuru prime (large UK/US/IT/DE/IN/diaspora demand); 🟠 MEDIUM Nairobi secondary Kilimani / Hurlingham; 🟠 MEDIUM Diani south coast (UK/IT/DE retiree); 🔴 LOW Mombasa city / Nakuru / Kisumu / Naivasha SGR-corridor; VERY LOW rural agricultural (foreign-buyer barred); **Karen British-cultural roots + Aga Khan University Hospital flagship** anchor expat liquidity
- **Quirks**: **NO golden-visa via real estate (UNIQUE absence in EAC)**; **agricultural land restricted to citizens per Constitution Art. 65**; 99-yr leasehold cap on non-citizen freehold-equivalents; **Class A1 Investor USD 100k business / Class K Resident KES 200k+/yr passive / PR 7yr / Citizenship 7yr + Swahili (dual allowed since 2010)**; ~55M pop (Nairobi Metro 5M, Mombasa 1.4M); SGR Mombasa-Nairobi-Naivasha-Kisumu drives corridor RE; **Safaricom 5G + Airtel + Telkom + M-PESA universal in admin (unique to KE)**; coworking Nairobi Westlands/Karen/Kilimani — iHub / Nailab / Workstyle / The Mint Hub (one of Africa's strongest startup ecosystems); NHIF + Social Health Insurance Fund (SHIF — phased 2024-25 reform); private flagship Aga Khan University Hospital Nairobi + Karen Hospital + Nairobi Hospital + MP Shah Hospital; medivac to ZA/UK for complex; English + Kiswahili co-official; KES BCK-managed float (relatively stable; M-PESA reduces some FX friction); SHIF reform 2024-25 + 2024 Finance Bill protests + Generation Z political-economy material; **Gilgil-Naivasha-Nakuru-Kisumu SGR Phase 2A delays** affect corridor RE
