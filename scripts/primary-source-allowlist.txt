# Primary-source allowlist for audit-confidence.py
#
# Domains here count as "primary government / regulator" alongside the gov/gouv/gob
# pattern matches in the script. Use this for central banks, statistics agencies, and
# regulators whose domain doesn't carry a country gov suffix.
#
# Format: one hostname per line. Comments start with #. Blank lines ignored.
# Hostnames are matched exact (case-insensitive). Add `www.` variants if both used.
#
# Acceptance criteria for adding a domain:
#   - Officially the primary publisher of the data being cited (regulator's own portal,
#     not a wrapper or aggregator).
#   - Not a private-sector commercial site (Knight Frank, JLL, etc. — those are secondary).
#   - Not a forum / blog / wiki.
